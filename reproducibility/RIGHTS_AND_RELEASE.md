This directory contains the original non-image recount/S4 payload. The main
branch's earlier unlicensed state remains in Git history. The version1.0.0 local
candidate adds MIT code/documentation and CC BY4.0 author-generated record terms
as selected by the author; final publication approval is still required.

Exact coverage is root LICENSE_SCOPE.json. External dependencies and BraTS input
data retain their own terms. No license for absent masks, MRI or NPZ is granted.
Repository visibility, admin permissions and hashes do not establish ownership.
The authors' final approval must cover redistribution and licensing of all
inventoried files, including the author-written code in frozen/vendor.

The portable core-search adapter is in ../full_search; it does not change this
subpackage's recorded-row/ledger-only verification commands. See root README,
DATA_ACCESS.md and THIRD_PARTY_NOTICES.md for actual capabilities and attribution.
