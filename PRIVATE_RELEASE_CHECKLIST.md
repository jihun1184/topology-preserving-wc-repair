# Private repository review checklist

This checklist is internal and does not establish publication permission.

- [ ] Confirm that the 22 preserved `reproducibility/` files are the intended initial GitHub scope.
- [ ] Confirm all authors/contributors/institutional rights for retained scripts and derived data.
- [ ] Choose and approve a **code** license and, separately, terms for the derived CSV/JSON data (no license is currently granted).
- [ ] Confirm no proprietary, private-path, personal or third-party content is unintentionally included.
- [ ] Verify `reproducibility/verify_package.py`, `verification/reaggregate_r1_2.py`, and `s4_records/verify_s4_records.py` with ordinary Python.
- [ ] Keep full OR4/ESM_4.zip, original images/masks, upstream search stack, NPZ inputs, and internal author-review documents out of this repository unless separately approved.
- [ ] Finalize the public README, manuscript citation and actual availability statement only after release approval.
- [ ] Only then change GitHub repository visibility to **Public** (if public release is chosen).
